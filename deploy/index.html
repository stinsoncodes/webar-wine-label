WebAR tracking spike

19 Crimes label · MindAR feasibility test

Tracking test → Green wireframe locks to the label. This is the one that matters. Camera check → Live preview and a focus score. Use it to find the right holding distance.

How to run it

  1. Open Tracking test and allow camera access. It uses the rear camera.
  2. Centre the label in frame, filling roughly a third of the screen height.
  3. Hold steady until it reads LOCKED, then tap Reset stats — everything before that point is setup noise and shouldn't count.
  4. Hold still for 5 seconds, then rotate the bottle slowly through ±40°. Tilt it. Move it nearer and further.
  5. Report Locked (session) and Lock / loss events, and whether the wireframe sat squarely on the label or swam around.

Reading the result

  1. >90% through rotation — good, build it.
  2. 60–90% — try multi-angle targets before concluding.
  3. <60% — the target needs rethinking, not the code.

Tuning

The tracker's filters are query-string overridable, e.g. tracking-test.html?filterBeta=0.01. Params: targets, filterMinCF, filterBeta, missTolerance, warmupTolerance.
